## 2. Change desired state in Git: replicas 2 -> 3 (kubectl never touches the Deployment)

## 3. Drift: someone scales it by hand, outside Git
$ kubectl -n gitops-demo scale deploy web --replicas=1
deployment.apps/web scaled
$ kubectl -n gitops-demo get deploy web   # immediately after
NAME   READY   UP-TO-DATE   AVAILABLE   AGE
web    3/1     3            3           25s
$ kubectl -n gitops-demo get deploy web   # a few seconds later: selfHeal restored what Git says
NAME   READY   UP-TO-DATE   AVAILABLE   AGE
web    3/3     3            3           47s
  sync=Synced health=Healthy revision=b7aa864

$ kubectl -n gitops-demo get events | grep -i scal
