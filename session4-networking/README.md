Networking homework. Ran on minty@homelab. Screenshots are in the screenshots folder.

01-hostname-ip-ping.png is hostname, ip addr, and ping to 8.8.8.8. hostname is the machine name. ip addr shows interface addresses. ping checks if a host is reachable.

02-dns-arp-ss-route.png is dig, ip neigh, ss, and ip route. dig turns a name into an IP. ip neigh is ARP (IP to MAC on the LAN). ss shows listening ports. ip route shows where packets go, including the default gateway.
